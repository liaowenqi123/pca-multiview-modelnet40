# V3: ResNet18 + 6-View Symmetric Fusion + Confidence-Gated Per-View Classifiers + Dim Reduction

## 一句话概括

在 v2 的对称融合基础上，增加两个改进：(1) 融合前各视角独立线性投影降维，(2) 每个融合后视角有自己的分类头，由共享置信度门控决定权重，与融合路径输出相加。

## 核心动机

### 想法一：每个视角应该能独立投票

正面看到一辆车的特征 → 应该能判断是车。侧面看到 → 也应该能。但**不强制**：如果某个视角确实看不清（比如俯视分不清碗和盘子），置信度门控会自动降低它的贡献。

### 想法二：融合前的特征应该先投影到同一语义空间

不同方向看到的特征虽然维度相同，但"语义"不同。正面视角第 128 位可能代表"有机翼"，侧面视角第 128 位可能代表"有车轮"。各自线性投影就是把它们对齐到同一个可比较的空间，然后再 concat 融合。

## 逐阶段张量形状

| 阶段 | 形状 | 说明 |
|------|------|------|
| 原始点云 | `(2048, 3)` | 单样本 |
| PCA 对齐 | `(2048, 3)` | 归一化到 [-1,1] |
| 六视图投影 | `(6, 3, 224, 224)` | 三对(正/反)视图 |
| 视图合并 | `(B*6, 3, 224, 224)` | batch 维度展开 |
| Backbone 输出 | `(B*6, 512, 7, 7)` | ResNet18 layer4 |
| 池化后 | `(B*6, 512)` | AdaptiveAvgPool → squeeze |
| 恢复视角 | `(B, 6, 512)` | reshape |
| 对称 max-pool | `(B, 3, 512)` | max(正, 反) → PCA 不变 |
| | | |
| **Path A — 各自投影** | | |
| 投影 0/1/2 | `(B, 256)` × 3 | Linear(512→256) + BN + ReLU |
| concat | `(B, 768)` | 3 × 256 |
| 分类 MLP | `(B, 40)` | 768→512→256→40 |
| | | |
| **Path B — 门控独立决策** | | |
| 置信度投影 | `(B, 1)` | 共享 Linear(512→1) → sigmoid |
| 独立分类头 i | `(B, 40)` | Linear(512→40) |
| 门控后贡献 | `(B, 40)` | sigmoid * view_logits |
| 三视角求和 | `(B, 40)` | gated_0 + gated_1 + gated_2 |
| | | |
| **最终** | `(B, 40)` | logits_fus + logits_gated |

## 为什么置信度投影是共享的？

"这个视角的特征值不值得用来做独立判断" —— 这是一个视角无关的通用问题。不管是从 xy、xz 还是 yz 看，判断标准应该是统一的。共享权重也避免了每个视角各自学一套置信度导致训练困难。

置信度投影初始化 bias = -1.0，sigmoid(-1) ≈ 0.27，初始阶段每个视角贡献约 27%，以融合路径为主。训练中模型自己学会在需要时提升某个视角的置信度。

## 关键数值

| 项目 | v2 | v3 |
|------|-----|-----|
| Backbone | ResNet18 | ResNet18 |
| 视图投影 | 无 | 各自 512→256, 不共享 |
| 融合输入 | 1536 (3×512) | 768 (3×256) |
| 视角分类头 | 无 | 3× Linear(512→40) |
| 置信度门控 | 无 | 共享 Linear(512→1) |
| 参数量 | ~11.4M | ~12.0M |
