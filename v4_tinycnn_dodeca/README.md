# V4: TinyCNN + 十二面体 6 视图 + 5 通道投影

## 一句话概括

扔掉预训练模型，手写一个 ~98K 参数的 TinyCNN，用十二面体的 6 个非对向视角做 5 通道投影（count / min_z / max_z / mean_z / z_range），配合 V3 的门控架构。**~300K 参数，比 V3 小 40 倍。**

## 两个关键洞察

### 1. 5 通道 = 天然的 PCA 方向不变性

从 +n 方向看点云，和从 -n 方向看，5 通道编码了什么？

| 通道 | +n 方向 | -n 方向 | 结论 |
|------|---------|---------|------|
| count (密度) | 相同投影平面，相同分布 | 相同 | 冗余 |
| min_z | min(p·n) | min(-p·n) = -max(p·n) | 与 max_z 互换 |
| max_z | max(p·n) | max(-p·n) = -min(p·n) | 与 min_z 互换 |
| mean_z | mean(p·n) | -mean(p·n) | 取负 |
| z_range | max-min | 不变 | 相同 |

**所以只需每个方向对取一个，6 个视角就够了，不需要 12 个，也不需要对称融合。**

### 2. 投影图是简单几何，不需要 ResNet

密度图和深度图没有纹理、光照、复杂背景。TinyCNN 4 层卷积 + 3×3 kernel 足够提取判别信息。

## 数据流向

```
原始点云 (2048, 3)
    │
    ▼ PCA 对齐
对齐点云 (2048, 3), 坐标 ∈ [-1, 1]
    │
    ▼ 十二面体 6 视角 × 5 通道投影 (56×56)
    ├─ 视角0 (n₀)  → (5, 56, 56)
    ├─ 视角1 (n₁)  → (5, 56, 56)
    ├─ 视角2 (n₂)  → (5, 56, 56)
    ├─ 视角3 (n₃)  → (5, 56, 56)
    ├─ 视角4 (n₄)  → (5, 56, 56)
    └─ 视角5 (n₅)  → (5, 56, 56)
    │
    ▼ 归一化 (5ch: [0,1]→[-1,1])
输入张量 (B, 6, 5, 56, 56)
    │
    ▼ 展开到 batch 维度
(B*6, 5, 56, 56)
    │
    ▼ 共享 TinyCNN
    ├─ Conv(5→32)  + BN + ReLU → MaxPool(2) → (28, 28, 32)
    ├─ Conv(32→64) + BN + ReLU → MaxPool(2) → (14, 14, 64)
    ├─ Conv(64→128)+ BN + ReLU → MaxPool(2) → (7,  7,  128)
    └─ Conv(128→128)+BN + ReLU → AdaptiveAvgPool(1) → 128d
(B*6, 128)
    │
    ▼ 恢复视角维度
(B, 6, 128)
    │
    │     ╔═══════════════════════════════════╗
    │     ║  每个视角 (B, 128) 做两件事        ║
    │     ╚════════╤══════════════════════════╝
    │              │
    │  ┌───────────┼───────────┐
    │  │                       │
    │  ▼ Path A                 ▼ Path B
    │  融合路径                 门控独立决策
    │  │                       │
    │  [投影_i:128→32]         [置信度:128→1→σ]
    │  BN + ReLU               │
    │  │                       ×
    │  ▼                       ▼
    │  32d                    [分类头_i:128→40]
    │                          │
    │                          logits_i (B,40)
    │                          × g_i
    │                          = gated_i
    │
    ▼                          ▼
concat(6×32)              sum([gated_0, ..., gated_5])
= (B, 192)                = (B, 40)
    │                          │
    ▼ 分类 MLP                 │
    192 → 64 → 40               │
    │                          │
    ▼                          ▼
logits_fus (B,40)        logits_gated (B,40)
    │                          │
    └────────── + ─────────────┘
                │
                ▼
        final_logits (B, 40)
```

## 逐阶段张量形状

| 阶段 | 形状 | 说明 |
|------|------|------|
| 原始点云 | `(2048, 3)` | 单样本 |
| PCA 对齐 | `(2048, 3)` | 归一化 [-1,1] |
| 十二面体投影 | `(6, 5, 56, 56)` | 6 视角 × 5 通道 |
| 归一化 | `(6, 5, 56, 56)` | [0,1]→[-1,1] |
| 展开 batch | `(B*6, 5, 56, 56)` | |
| Stage1 Conv | `(B*6, 32, 28, 28)` | MaxPool2 |
| Stage2 Conv | `(B*6, 64, 14, 14)` | MaxPool2 |
| Stage3 Conv | `(B*6, 128, 7, 7)` | MaxPool2 |
| Stage4 Conv | `(B*6, 128, 7, 7)` | |
| AdaptiveAvgPool | `(B*6, 128)` | squeeze |
| 恢复视角 | `(B, 6, 128)` | |
| 投影降维 | `(B, 32)` × 6 | Linear(128→32)+BN+ReLU |
| concat | `(B, 192)` | 6 × 32 |
| 分类 MLP | `(B, 40)` | 192→64→40 |
| 置信度 × 6 | `(B, 1)` × 6 | 共享 Linear(128→1)→sigmoid |
| 视角分类 × 6 | `(B, 40)` × 6 | Linear(128→40) |
| 门控求和 | `(B, 40)` | |
| **最终** | `(B, 40)` | fus + gated |

## 关键数值

| 项目 | V3 | V4 |
|------|-----|-----|
| Backbone | ResNet18 (~11M) | TinyCNN (~98K) |
| 分辨率 | 224×224 | 56×56 |
| 像素数 | 150K/视图 | 3.1K/视图 |
| 通道数 | 3 | 5 |
| 视角数(融合) | 3 | 6 |
| 总参数 | ~12M | **~300K** |
| 每 epoch 时间 | ~300s | 预计 <60s |
| 预训练 | ImageNet | 无 |

## 运行

```bash
python v4_tinycnn_dodeca/train.py --epochs 100 --batch_size 64
```
