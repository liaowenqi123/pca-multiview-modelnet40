# V6: V3 + PointNet 交叉注意力

## 一句话概括

在 V3 的双路径门控架构上，新增一条轻量 PointNet 路径：原始点云经自注意力 + PointNet 编码后，与 V3 的 3 个视角特征做交叉注意力，结果与 V3 logits 相加。

## 核心动机

V3 的视角特征是 2D 投影的抽象 — 模型"看到"了密度和深度图，但不知道这些像素对应 3D 空间中哪些点。V6 通过交叉注意力建立 **视角 ↔ 点云** 的直接连接。

## 数据流向

```
                      ┌─────────── V3 路径 ───────────┐
                      │                                │
六视图 (6,3,224,224) → ResNet18 → sym max-pool        │
                      │            (B, 3, 512)          │
                      │              │                  │
                      │     ┌────────┼────────┐         │
                      │     │                  │         │
                      │     ▼ Path A           ▼ Path B   │
                      │  各自投影降维         置信度门控      │
                      │  3×256→concat         共享 512→1    │
                      │     │                  ×           │
                      │  融合分类 MLP        独立分类头 ×3   │
                      │     │                  │           │
                      │   logits_fus      logits_gated    │
                      │     └───── + ────────┘            │
                      │              │                     │
                      │         logits_v3 (B, 40)         │
                      │              │                     │
                      │              │   (B, 3, 512)      │
                      │              │       ↓ Q          │
                      └──────────────┼───────────────────┘
                                     │
原始点云 (2048, 3) ──┬── 自注意力 ──┼── PointNet ──→ K, V ──┤
                     │  (无embedding)  │                        │
                     │              cross-attention            │
                     │       Q_v3 · K^T / √d → softmax         │
                     │          weighted sum of V               │
                     │            (B, 3, 64)                    │
                     │            mean pool                     │

                     │               │                          │

                     │               │                          │

                     │               │                          │
                     └─────────────── + ───────────────────────┘
                                     │
```

## 关键模块

### 自注意力（无 embedding）

直接在 PCA 对齐后的坐标 `(2048, 3)` 上做多头注意力，不做可学习的 embedding。3 个线性层将坐标投影到 64 维做 Q/K/V，多头重组后标准 attention + residual + LayerNorm。

设计理由：坐标本身就包含空间结构信息，不需要额外的 embedding。自注意力让每个点感知其他点的空间关系。

### PointNet

对自注意力输出做 per-point MLP（Conv1d）：

```
(2048, 64) → Conv1d(64→64) → BN → ReLU
           → Conv1d(64→128) → BN → ReLU
           → Conv1d(128→128) → BN → ReLU
           → (2048, 128)
```

输出为 **per-point 特征**，不做全局 max-pool。每个点保留独立的特征表达，供交叉注意力使用。

### 交叉注意力

三个视角各向 2048 个点"提问"：

| 符号 | 来源 | 形状 | 含义 |
|------|------|------|------|
| Q | V3 3 个融合视角特征 | `(B, 3, 64)` | "从每个视角看，我应该关注什么？" |
| K | PointNet 每点特征 | `(B, 2048, 64)` | "每个点的身份标识" |
| V | PointNet 每点特征 | `(B, 2048, 64)` | "每个点的内容" |

`attention_weights = softmax(Q·K^T/√d)` → `(B, 3, 2048)`

每个视角得到 2048 个点的重要性分布。

`weighted_v = attention @ V` → `(B, 3, 64)` → mean pool → `(B, 64)`

## 逐阶段张量形状

| 阶段 | 形状 | 模块 |
|------|------|------|
| 原始点云 | `(B, 2048, 3)` | 输入 |
| SA Q/K/V 投影 | `(B, 4, 2048, 16)` | 4 头自注意力 |
| SA 残差 + LN | `(B, 2048, 64)` | |
| PointNet MLP | `(B, 2048, 128)` | 3 层 Conv1d |
| K, V 投影 | `(B, 2048, 64)×2` | |
| Q (来自 V3) | `(B, 3, 64)` | Linear(512→64) |
| 交叉注意力分数 | `(B, 3, 2048)` | Q·K^T |
| 加权 V | `(B, 3, 64)` | attention @ V |
| 视角池化 | `(B, 64)` | mean |
| 输出 | `(B, 40)` | Linear(64→128→40) |

## 关键数值

| 项目 | V3 | V6 |
|------|-----|-----|
| Backbone | ResNet18 | ResNet18 |
| V3 路径参数 | ~12M | ~12M |
| PointNet 路径 | 无 | **~80K** |
| 总参数 | ~12M | ~12.1M |
| 训练语义 | 视角→分类 | 视角↔点云→分类 |
